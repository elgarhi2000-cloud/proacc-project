# ProACCDB - Minimal Node.js SQL Server Example

شرح سريع (بالعربية): مشروع بسيط بـ Node.js يربط لقاعدة بيانات SQL Server (ProACCDB) ويعرض نقطتي نهاية للاختبار.

المتطلبات:
- Node.js 16+ مثبت

التشغيل:
1. انسخ `.env.example` إلى `.env` وعدّل القيم إذا لزم.

```bash
npm install
# للتشغيل في التطوير مع إعادة التشغيل التلقائي
npm run dev
# أو للتشغيل العادي
npm start
```

نقاط النهاية:
- `GET /test` : تحقق من اتصال قاعدة البيانات (ترجع `1` إذا نجح)
- `GET /tables` : يعرض حتى 50 جدولاً من قاعدة البيانات

مثال اختبار (بعد التشغيل):

```bash
curl http://localhost:3000/test
```

ملاحظة أمان: لا تحفظ كلمات المرور في مستودع العام. استخدم أسرار بيئة في الإنتاج.
